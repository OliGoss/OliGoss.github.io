# Théorie de la décision et théorie des jeux

The source combines five French lecture-note handouts originally taught at the École nationale des ponts et chaussées between 2002 and 2004.

Build from this directory with:

```sh
latexmk -pdfps theorie-decision-jeux.tex
```

The `latex -> dvips -> ps2pdf` route is required because the original diagrams use PSTricks.
